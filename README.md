# API REST - Proyecto Final Spring Boot

Este proyecto es una API REST desarrollada con Java y Spring Boot como parte de mi formación en backend.

## Tecnologías utilizadas
- Java
- Spring Boot
- Spring Data JPA
- Maven

## Estructura
- Controller
- Service
- Repository
- Model
- DTO
- Exception

## Funcionalidades
- CRUD de clientes, productos y ventas
- Manejo de stock
- Consultas específicas (ventas del día, mayor venta)
